# World Cup Predictor Website

A static 2026 FIFA World Cup predictor site with official group stage teams and fixtures.

## Files

- `index.html` — main page with predictor UI, team groups, and schedule
- `styles.css` — layout, group cards, and schedule styling
- `script.js` — 48-team predictor logic, group listings, and schedule rendering

## Usage

Open `index.html` in a browser to view the predictor.

## Features

- Full 48-team World Cup squad list with group assignments
- Official group stage fixture schedule for all groups A through L
- Match predictor with team selection, score input, and confidence estimate
- Bracket forecast for quarterfinal-style matchups
- Live tips that update based on selected teams and predicted score gap
